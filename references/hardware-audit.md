# Hardware / Embedded / Robotics Audit

Apply this review when the project includes physical devices, PCB/electronics, firmware, sensors, actuators, robotics, edge compute, or custom mechanical integration.

Assess separately:

- software readiness;
- firmware readiness;
- electronics readiness;
- mechanical readiness;
- manufacturing readiness;
- system integration readiness.

Inspect applicable evidence for:

- schematics;
- PCB layout;
- BOM and component availability;
- power architecture;
- battery/charging;
- sensors and actuators;
- firmware architecture;
- boot/update path;
- communication protocols;
- drivers;
- calibration;
- timing/real-time constraints;
- thermal behavior;
- EMC/EMI concerns;
- enclosure/mechanical fit;
- test fixtures;
- fault handling;
- watchdogs;
- field diagnostics;
- manufacturing test;
- serviceability;
- prototype cost;
- estimated production cost;
- supplier concentration risk.

A simulator or schematic alone is not evidence of integrated hardware readiness. A working prototype is not evidence of manufacturing readiness.

Where measurements exist, distinguish measured values from estimates.
