# PROJECT ROADMAP

## Current Bottleneck

State the bottleneck, evidence, affected modules, and why it dominates current progress.

## Highest-Leverage Actions

Rank the top actions by expected readiness gain per unit of effort.

For each action include:

- priority;
- impact;
- effort;
- risk reduction;
- dependencies;
- unlocks;
- definition of done;
- evidence required for completion.

## NOW

Only work that should start immediately.

## NEXT

Work that becomes valuable after NOW items are complete.

## LATER

Important but non-immediate work.

## OPTIONAL

Useful but non-critical improvements.

## DEFER

Work whose timing is premature.

## REMOVE / STOP DOING

Work that should be deleted, abandoned, or intentionally stopped because it adds low value, duplicates another direction, or increases risk without enough return.

## Next Version Scope

Define included scope, excluded scope, acceptance criteria, quality gates, and evidence needed to call the version complete.
